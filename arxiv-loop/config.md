# arXiv 循环方针

> 这是活文档，每轮循环后可能被修改。版本号递增。

## 使命（v1）

在学术前沿的噪声中，找到可能改变我们理解世界方式的信号。

不找枝节改进，不找窄领域自嗨，只找重大的、可能的、改变规则的东西。

## 两个专注方向

### 方向 A：AI 与 Agent

- Agent 架构的演进
- AI 系统设计（不是模型训练技巧，是系统层面的设计思路）
- 人机协作的新范式
- AI 能力边界的重新定义

### 方向 B：广义信息论 × 人类理解

- 语义信息的量化和理论突破
- 广义信息论（超越 Shannon 的信息度量）
- 人类理解力的构建机制
- 知识如何被组织、传播、理解的底层逻辑

## 品味：什么值得产出

### 1. 重大发现
- 挑战现有范式的前提，而不是在框架内改进
- 实验结果和"常识"相反
- 一个领域的突破意外解释了另一个领域的问题
- 如果成立，很多事情要重新想

### 2. 有趣的思路
- 提出了新的看问题的角度
- 连接了之前没人连接的两个概念
- 方法不一定成熟，但方向让人兴奋
- 看完会想"为什么之前没人这么想"

## 不要什么

- 增量改进（X benchmark 提升 N%）
- 窄领域内部自嗨，外人无法理解价值
- 纯工程实现没有认知洞察的
- 热度高但实质空洞的

## 产出标准

让读者在 10 秒内感受到"这件事为什么重要"。

## 素材来源（双轨）

### 轨道 1：最新前沿
- 范围：cs.AI、cs.CL、cs.IT（信息论）、cs.LG、q-bio（交叉领域）
- 终止条件：当天新内容全部扫完
- 产出要求：有就产出，没有就记录"今日无新发现"

### 轨道 2：历史经典
- 历史上影响力大（高引用）但不广为人知的论文
- 通过 Semantic Scholar API 按引用数发现
- 筛选标准：引用数高 + 普通人几乎没听过 + 用大白话能讲明白
- 这类论文不追时效，适合穿插在日常内容中

## 影响力指标

- 通过 Semantic Scholar API 查询引用数和被引速度
- 最新论文：引用数不作为硬性门槛（新论文还没积累引用），但关注作者/机构背景
- 历史论文：引用数是核心筛选指标，优先找"引用数高但大众认知度低"的

## 偏好加权（评估时叠加）

> 通用评估分（eval.md）计算完成后，按方向匹配度加权。
> 这是个人偏好层——换人使用时修改本节即可。

| 匹配程度 | 加权 | 示例 |
|---------|------|------|
| 方向 B 核心 | +4 | 语义信息论、理解力机制、认知建模 |
| A∩B 交叉 | +3 | AI + 认知/信息论/理解力 |
| 方向 A 且有认知洞察 | +2 | 不只是技术进步，还改变了对 AI 的认知 |
| 方向 A 纯技术但范式级别 | +1 | 架构突破、能力边界重新定义 |
| 不沾边 | +0 | 通用评分不加权 |
