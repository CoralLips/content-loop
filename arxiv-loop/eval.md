# 评估规则（通用）

> 适用于任何方向的内容评估。个人偏好见 config.md。
> 这是通用机制层——换人使用时本文件不需要修改。

## 质量维度

### 1. 认知冲击（权重 ×3）

读完之后，读者对世界的某个假设会被打破或重建吗？

| 分值 | 标准 | 典型信号 |
|------|------|---------|
| 3 | 颠覆 — 一个广泛持有的假设被证伪 | "原来 X 根本不是这样" |
| 2 | 刷新 — 提供了全新的看问题角度 | "没想到还能这么看" |
| 1 | 补充 — 增加了一个有趣的信息点 | "哦，有这么个事" |
| 0 | 无感 — 看完说不出学到了什么 | "所以呢？" |

稀缺性内含于此：如果一个观点已经被中文互联网广泛传播，它对读者的认知冲击已经被消耗过了，分数自然低。

### 2. 吸引力（权重 ×2）

内容能在多大程度上抓住并留住注意力？

**开头（Hook）**：第一句话能让人停下来吗？
- 强模式：反直觉、重新定义、冲突、规模震撼
- 弱模式："最近有研究发现..."、"X 领域提出了..."

**后续（可讲性）**：核心内容有没有故事性、趣味性，能不能让人一直读下去？

| 分值 | 标准 |
|------|------|
| 3 | 开头让人停下来，后续越读越有意思 |
| 2 | 开头强但后续需要功夫，或开头一般但内容扎实 |
| 1 | 需要大量包装才能让人读进去 |
| 0 | 无论怎么包装都很难让非专业读者感兴趣 |

### 3. 通俗可转化性（权重 ×1）

核心概念能不能用日常语言让非专业人听懂？

| 分值 | 标准 | 示例 |
|------|------|------|
| 2 | 天然通俗 — 自带日常类比 | "大脑是预言机"、"Shannon 扔掉了意义" |
| 1 | 需要桥接 — 要构造类比，但做得到 | 用"翻译"解释语义信息论 |
| 0 | 极难转化 — 太抽象/太数学，硬讲会变成"听君一席话" | 纯范畴论证明 |

注意：通俗可转化性 ≠ 吸引力。一个内容可以很酷但讲不清（高吸引力低通俗），也可以好懂但无聊（高通俗低吸引力）。

### 4. 学术可信度（权重 ×1）★ 2026-04-22 加入

为防止 arxiv 预印本中的"看起来惊艳但实际站不住脚"的工作被放大，评估时必须判断学术权威信号。

| 分值 | 标准 | 典型信号 |
|------|------|---------|
| 3 | 顶会/顶刊接收 or 作者有明确权威背景 | NeurIPS/ICML/ICLR/ACL/CVPR/AAAI/Nature/Science；首末作 h-index ≥30；Top 20 CS 机构 |
| 2 | 次级会议 or 中等权威 | 次级 AI 会议接收；首末作 h-index 10-30；Top 50 CS 机构；大厂研究院（Google/Meta/Anthropic/DeepMind/OpenAI） |
| 1 | 纯 arxiv 预印本但作者/机构可查 | 有机构背景但非 Top 100；作者有博士学位 + 多篇合作者论文 |
| 0 | 纯 arxiv + 个人/无法验证 | 无机构 / h-index 低 / 没有合作者网络 / 看起来像 crackpot |

**判定信号的来源**（按顺序尝试）：
1. Semantic Scholar API: `https://api.semanticscholar.org/graph/v1/paper/arxiv:{id}?fields=authors,venue,citationCount,influentialCitationCount`
2. 论文 PDF 首页的机构信息
3. 作者 Google Scholar 个人页面（h-index）

**为什么不做硬门槛**：新突破常来自 arxiv 预印本（如 DeepSeek-R1 发布时未经审稿），硬过滤会漏掉真正的新发现。学术可信度作为第 4 维参与总分，**低可信度会被高认知冲击部分补偿**，但一个 5 分冲击 + 0 分可信的论文总分不会比 4 分冲击 + 2 分可信的高太多——这正是我们想要的平衡。

## 计分

```
总分 = 认知冲击(0-3)×3 + 吸引力(0-3)×2 + 通俗可转化性(0-2)×1 + 学术可信度(0-3)×1

满分：9 + 6 + 2 + 3 = 20
```

## 门槛

> 首次校准（2026-04-16）：queue 已经过扫描过滤（7%入选），加上偏好加权，
> 原门槛（≥13）导致 82% 素材通过。根据实际分布上调。
> 2026-04-22 加入学术可信度（第 4 维，满分 +3），门槛相应上调。

| 总分（含偏好加权 + 可信度后） | 判定 | 去向 |
|-----------------------------|------|------|
| ≥22 | 必发 | → 生成终稿 → unpublished/ |
| 17-21 | 优先发 | → 生成终稿 → unpublished/ |
| 12-16 | 备选 | 留在 queue，排期空闲时再评估 |
| <12 | 淘汰 | 标记 ❌，不再参与评估 |

## 排序因子（不计入分数）

同分时按以下顺序 tiebreak：
1. **时效敏感度** — 时效高的先发（紧跟最新突破 > 本月热点 > 经典回顾）
2. **话题多样性** — 和最近已发布内容避免撞车（不连续发同类）
3. **转化成本** — 素材信息完整的先发（生产效率）

## 偏好加权

通用评分完成后，加载 config.md 中定义的个人偏好加权，叠加到总分上。
偏好加权是加法（+N），不是乘法，避免放大效应。
具体加权值由 config.md 定义。

## 去重

评估时检查 published/ 中已发布内容，对以下情况降权或排除：
- 同一篇论文已发布 → 排除
- 同一论文的后续/相关工作 → 不排除，但标注关联
- 同一话题已发布过类似角度 → 降 2 分
