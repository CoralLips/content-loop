# 越会推理的 AI 越不合作——要让它们合作，别靠"讲道理"，靠合约

> ⬜ 待审核 | 品味命中：重大发现/有趣思路 | 方向：A（有认知洞察）

## 简单说

让两个 LLM 玩囚徒困境。直觉说：推理能力越强，越应该看清"合作更优"，对吧？

实验结果完全反过来：**推理能力越强的 LLM，越倾向于叛变**。single-shot（一次性）博弈里，几乎所有现代 LLM——不管开不开推理、大小——全部选叛变。这个趋势在多篇论文里都出现了。

这篇工作的反转在于：如果直接劝它们"合作吧"不起作用，那么**什么能让它们合作？** 作者从博弈论里拉了 4 个经典机制来测：重复博弈、声誉系统、第三方调解、合约。

结果：**调解和合约最有效**，重复博弈（"下次还会见面，你最好对我好点"）在**对手换来换去**时几乎失效。更反直觉的是——当让模型群体经历**演化筛选**（淘汰低收益者）时，合作频率不降反升。

一句话结论：**现代 LLM 不是不懂合作的好处，它们是在没有强制结构时默认"个人利益最大化"。要它们合作，别靠对话感化，靠可执行的规则**。

- 日期：2026-04-16
- 团队：Emanuel Tewolde, Xiao Zhang, David Guzman Piedrahita, Vincent Conitzer, Zhijing Jin

## 原文摘要（完整）

It is increasingly important that LLM agents interact effectively and safely with other goal-pursuing agents, yet, recent works report the opposite trend: LLMs with stronger reasoning capabilities behave _less_ cooperatively in mixed-motive games such as the prisoner's dilemma and public goods settings. Indeed, our experiments show that recent models -- with or without reasoning enabled -- consistently defect in single-shot social dilemmas. To tackle this safety concern, we present the first comparative study of game-theoretic mechanisms that are designed to enable cooperative outcomes between rational agents _in equilibrium_. Across four social dilemmas testing distinct components of robust cooperation, we evaluate the following mechanisms: (1) repeating the game for many rounds, (2) reputation systems, (3) third-party mediators to delegate decision making to, and (4) contract agreements for outcome-conditional payments between players. Among our findings, we establish that contracting and mediation are most effective in achieving cooperative outcomes between capable LLM models, and that repetition-induced cooperation deteriorates drastically when co-players vary. Moreover, we demonstrate that these cooperation mechanisms become _more effective_ under evolutionary pressures to maximize individual payoffs.

## 论文核心内容

### 动机与背景
LLM Agent 之间的安全互动越来越重要。多篇近期研究报告了一个反直觉趋势：**推理能力越强，越不合作**。作者想做第一个系统性比较研究——**什么机制能让理性 LLM 在均衡下选择合作**。

### 关键发现 / 方法

**四个社会困境**：
1. Prisoner's Dilemma（囚徒困境）
2. Traveler's Dilemma（旅行者困境）
3. Trust Game（信任博弈）
4. Public Goods Game（公共物品博弈）

**四种合作机制**：
1. **Repetition**：把游戏重复多轮，让"未来惩罚"影响当前决策
2. **Reputation**：引入声誉系统，玩家历史被公开
3. **Mediation**：引入第三方调解者，双方把决策权委托给他
4. **Contract**：签订合约，约定"按结果付款"

**主要发现**：

**RQ1（无机制基线）**：所有现代 LLM 在未修改的社会困境中**全部叛变**——不管是推理/非推理模型，不管大/小。

**RQ2（机制有效性）**：**Contract（合约）和 Mediation（调解）最有效**。Repetition 和 Reputation 效果有限。

**RQ3（演化动力学）**：在纯粹的"最大化自己收益"的演化压力下，合作机制**反而更有效**——演化压力 boost 合作频率，提升集体福利。

**RQ5（重复与声誉）**：Repetition 诱导的合作在**对手多样化**时急剧退化。固定对手时 LLM 会"记住账"，换对手就恢复自利。

**RQ6（调解与合约）**：合约起效的关键是"可执行的结果条件"。调解起效的关键是"委托决策给一个共同信任的第三方"。

**决策理由分析**：
通过 LLM-as-Judge 分析推理内容，发现**绝大多数 LLM 决策都由"自利效用最大化"和"均衡策略"驱动**——模型不是"不懂合作好"，是"懂博弈论"，所以在没有机制时理性选择叛变。

### 结论
合作不是靠道德说教能得到的——它需要**可以在均衡下执行的结构性机制**。合约和调解是人类文明千年来的合作基础设施，在 LLM Agent 群体里也是最有效的。这对未来多 Agent 系统设计有直接意义：**别靠 prompt 教 Agent "要合作"，要在系统层给它们一个合约执行环境**。

## AI 分析

### 为什么值得关注

**差异化**：
- 大多数 LLM 社会困境研究停留在"报告 LLM 叛变"
- 这篇**系统性对比了四种博弈论机制**，用 LLM 作为测试床
- 不是把 LLM 当"拟人"，是当"理性 agent"测试机制设计
- 演化动力学视角：在淘汰压力下机制会不会退化？答案是反而强化

**独特性**：
- 把**博弈论经典机制设计**和 **LLM Agent 评估**结合——这在文献上是第一个
- 发现"重复博弈在对手变化时失效"——这对真实世界 Agent 系统重要：用户池是流动的，固定对手假设站不住
- 65 页 + 38 图 + 8 表 + 17 Listings，系统性实验质量

**贡献度**：
- **对 Multi-Agent 系统设计有直接指导意义**：AI Agent 群体需要合约/调解基础设施，不能只靠 prompt 约束
- **对 AI Safety 有战略意义**：越强的推理能力不等于越安全的协作——要在结构层保护合作
- **连接了博弈论和 LLM**：为把经典机制设计理论应用到 Agent 群体打开了实验路径

**局限**：
- 四个游戏都是简化博弈，现实合作更复杂
- LLM 的"叛变倾向"可能部分来自训练数据（游戏论教科书的"理性解"）
- 没有测 LLM 自己**设计**新合作机制的能力

### 和已有认知的关联
- **"Moloch 问题"**：集体理性和个体理性的冲突，LLM 版本
- **AS/CT 实验（02f）**：好人 AI 在推理模型里反而下降——和这里"推理越强越不合作"同源现象
- **演化博弈论**（Axelrod、Nowak）：经典理论在 LLM 群体里是否成立——这是第一个系统性验证
