# Agent 的记忆不只在"脑子"里——环境本身就是外部记忆

> ✅ 已通过评估 | 品味命中：有趣思路 | 方向：A（AI/Agent）+ B（认知/信息论）| ★ | 评估分15

## 简单说

你的购物清单、TODO 列表、笔记本——这些不是"辅助工具"，它们就是你记忆系统的一部分。认知科学里有个观点叫"情境认知"：智能行为不只靠大脑内部记忆，还靠主动利用环境中的资源。这篇论文首次在强化学习中形式化了这个直觉：**环境中的"制品"（artifact）可以充当 agent 的外部记忆，减少 agent 内部需要维护的信息量。** 用数学证明了某些环境观测（artifact）可以压缩 agent 需要记住的历史长度。这意味着：好的 agent 不是记忆力最强的，而是最会利用环境来"卸载"记忆的。
