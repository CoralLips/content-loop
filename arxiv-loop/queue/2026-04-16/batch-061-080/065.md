# AI 最大的瓶颈不是能力，是不知道什么时候该问人——判断力基准测试

> ✅ 已通过评估 | 品味命中：有趣思路 | 方向：A（AI/Agent）+ B（认知）| ★ | 评估分16

## 简单说

现在最强的 AI 编程 agent，给它完整的需求文档，它能搞定复杂任务。但如果需求文档不完整、有歧义呢？它不会问你——它会猜，然后做错。研究者发现：**AI agent 的瓶颈不是"能不能做"，而是"知不知道自己该问"。** 这叫"选择性上报"——知道什么时候自己干、什么时候问人。现有所有 benchmark 都测不了这个，因为它们给的指令都是完整无歧义的。HiL-Bench 是第一个测试 agent "知不知道自己不知道"的基准。

## AI 分析

**差异化**：所有人都在测 AI "能做什么"，这篇测"AI 知不知道自己做不了什么"。这是元认知层面的评估——和 queue 008（验证税）形成互补：008 说人类越来越难验证 AI，这篇说 AI 自己也不知道自己什么时候该停下来。

**贡献度**：对 Agent 架构有直接启示——好的 agent 不是什么都自己做，而是知道什么时候该问。这和 queue 010（Parallax：思考者不该执行）同一条线索。
