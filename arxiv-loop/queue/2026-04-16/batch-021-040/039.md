# AI Agent 架构缺了一层——知识、记忆、智慧、智能应该分开

> ✅ 已通过评估 | 品味命中：有趣思路 | 方向：A（AI/Agent）+ B（认知）| 17 分 → 02h

## 简单说

现在所有 AI Agent 的认知架构（包括最有影响力的 CoALA 和 LeCun 的 JEPA）都犯了一个错误：把"知识"和"记忆"混在一起。"巴黎是法国首都"（永远正确的事实）和"昨天用户说想吃意面"（会过时的记忆）被同样的机制存储和更新。这篇论文说：必须分开。提出四层分解——Knowledge（永久，只被更正的事实取代）、Memory（按艾宾浩斯曲线衰减）、Wisdom（需要证据才更新的判断）、Intelligence（瞬时推理，用完即弃）。每一层有根本不同的"持久性语义"。

## 原文摘要

CoALA and JEPA both lack an explicit Knowledge layer with its own persistence semantics. This gap produces a category error: systems apply cognitive decay to factual claims, or treat facts and experiences with identical update mechanics. We propose a four-layer decomposition (Knowledge, Memory, Wisdom, Intelligence) where each layer has fundamentally different persistence semantics.

## 核心内容

### 四层分解

| 层 | 持久性 | 例子 |
|---|--------|------|
| **Knowledge** | 永久，只被取代（supersession） | "巴黎是法国首都" |
| **Memory** | 艾宾浩斯衰减 | "用户昨天说想吃意面" |
| **Wisdom** | 证据门控修正 | "用户不喜欢辣的（基于多次观察）" |
| **Intelligence** | 瞬时，用完即弃 | 当前推理链中的中间结果 |

### 八个收敛点

论文从 Karpathy 的 LLM Knowledge Base 到 BEAM benchmark 的近零矛盾解决分数，识别了 8 个独立来源都指向同一个问题：缺乏持久性语义的区分。

### 核心论断

"No current framework or system provides distinct persistence semantics for knowledge, memory, wisdom, and intelligence."

## AI 分析

### 为什么值得关注

**差异化**：和 queue 028（记忆全景）、027（Memory Worth）、033（RoMem 相位旋转）串联看——所有这些记忆方案都在解决同一个根问题的不同侧面。这篇给出了最上层的架构框架。

**独特性**：四层分解不是任意的——每层有数学上不同的更新语义（取代/衰减/证据门控/瞬时）。这比"长期记忆 vs 短期记忆"的二分法精确得多。

**贡献度**：
- 对 Agent 架构：所有"记忆系统"的研究可以按这四层归类，找到自己在解决哪层的问题
- 和 thinking-tree 直接相关：碎片（Memory）、思路文件（Wisdom）、开放问题（Intelligence 的触发器）、已确认事实（Knowledge）——你的系统已经在做类似的分层
