# AI 什么时候该遗忘？一个只需要两个计数器的记忆治理方案

> ⬜ 待审核 | 品味命中：有趣思路 | 方向：A（AI/Agent）

## 简单说

AI Agent 的记忆会越积越多，但没有机制判断哪些记忆还有用、哪些该遗忘。这篇提出了一个极简方案"Memory Worth"：给每条记忆配两个计数器——被调用时任务成功了加 1，失败了加 1。随时间推移，每条记忆的"价值"会收敛到它的真实有用程度。过时的记忆自然沉到底部（MW=0.17），核心记忆保持在顶部（MW=0.77）。数学上证明了收敛性（ρ=0.89），而且只需要两个整数的存储开销。

## 原文摘要

We propose Memory Worth (MW): a two-counter per-memory signal that tracks how often a memory co-occurs with successful versus failed outcomes. We prove that MW converges almost surely to the conditional success probability. After 10,000 episodes, Spearman rank-correlation between Memory Worth and true utilities reaches ρ = 0.89 ± 0.02. The estimator requires only two scalar counters per memory unit.

## 核心内容

### Memory Worth 公式

```
MW(m) = 成功次数 / (成功次数 + 失败次数)
```

- MW 高 → 这条记忆经常在成功任务中被调用 → 有用
- MW 低 → 这条记忆经常在失败任务中被调用 → 有害或过时
- 数学证明：MW 几乎必然收敛到 p+(m)（给定这条记忆被调用时的条件成功概率）

### 关键数据

- 10,000 episodes 后 ρ = 0.89（和真实价值高度相关）
- 不更新的系统 ρ = 0.00（完全随机）
- 过时记忆：MW = 0.17（自动下沉）
- 专业记忆：MW = 0.77（自动浮上）

### 注意

MW 衡量的是**关联性**（共现）而非**因果性**。"这条记忆被调用时任务成功了"不等于"这条记忆导致了成功"。但论文认为关联性作为治理信号已经足够实用。

## AI 分析

### 为什么值得关注

**差异化**：大部分记忆系统的"遗忘"靠时间衰减（越旧越忘）或 LLM 判断（让 AI 自己决定忘什么）。MW 用结果反馈——不看记忆多老，看它有没有用。

**独特性**：两个计数器就够了。极简到不能再简。而且有数学收敛保证，不是启发式。

**贡献度**：
- 对 Agent 架构：记忆治理是长期运行 Agent 的核心需求，MW 给出了最小可行方案
- 和 queue 020（Thought-Retriever）、009（双轨记忆）、019（知识代谢）形成记忆系统的完整图景
- 对人类认知类比：人类也是"经常有用的记忆保持鲜活，很少用到的自然模糊"——MW 是这个过程的数学近似
