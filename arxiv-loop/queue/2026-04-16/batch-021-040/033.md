# 过时的记忆不用删——让它在复数空间里慢慢"旋转出局"

> ⬜ 待审核 | 品味命中：有趣思路 | 方向：A（AI/Agent）+ B（信息论）

## 简单说

AI 的记忆系统面临一个棘手问题：旧信息过时了怎么办？"美国总统是拜登"现在是错的，但直接删掉会丢失历史信息。RoMem 提出了一个优雅的解法：不删除，让过时的事实在复数向量空间里**旋转出相位**。每种关系有一个"波动速率"——"某国总统"旋转快（经常变），"某人出生于"旋转慢（永远不变）。过时的事实自然被旋转到和当前查询不匹配的相位上，自动沉底，不需要显式删除。时间从离散标签变成了连续的几何操作。

## 原文摘要

We introduce RoMem, a drop-in temporal knowledge graph module. A pretrained Semantic Speed Gate maps each relation's text embedding to a volatility score, learning that evolving relations should rotate fast while persistent ones should remain stable. Combined with continuous phase rotation, obsolete facts are rotated out of phase in complex vector space, so temporally correct facts naturally outrank contradictions without deletion.

## 核心内容

### 核心机制

每条关系有一个"语义速度门"（Semantic Speed Gate）：
- 输入：关系的文本嵌入（如"president of"）
- 输出：波动分数（volatility score）
- 高波动 → 快速旋转 → 旧值快速过时
- 低波动 → 缓慢旋转 → 几乎不变

### 关键数据

- 时间知识图补全：ICEWS05-15 上 MRR 72.6（SOTA）
- Agent 记忆时间推理：2-3x MRR 和准确率
- 静态记忆：零退化（永恒事实不受影响）
- 零样本泛化到金融领域

### 和其他记忆方案的区别

| 方案 | 处理过时信息 | 缺点 |
|------|-------------|------|
| 按时间排序 | 新的排前面 | 埋没永恒知识 |
| 直接覆盖 | 删掉旧的 | 丢失历史 |
| LLM 判断 | 每次调用 LLM | 极贵 |
| **RoMem** | 旋转出相位 | 自动、连续、保留历史 |

## AI 分析

### 为什么值得关注

**差异化**：所有现有方案要么删（丢历史）、要么排（埋永恒知识）、要么让 LLM 判断（太贵）。相位旋转是第四条路——用几何操作代替逻辑判断。

**独特性**：把时间建模为连续相位而非离散标签——这在概念上极其优雅。物理学里的波函数也是用相位编码时间演变的，这种跨学科类比不是巧合。

**贡献度**：
- 对 Agent 记忆：给"什么时候该遗忘"提供了不需要遗忘的替代方案——不删除，旋转
- 和 queue 027（Memory Worth）互补：027 判断"哪些该忘"，这篇说"不需要忘，让它自然沉底"
- 对信息论："信息的时效性"被编码为几何属性——又一种不同于 Shannon 的信息维度
