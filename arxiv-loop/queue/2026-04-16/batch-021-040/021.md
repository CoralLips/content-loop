# 给 AI 加记忆，Gemini 合作变少，Gemma 合作变多——模型"性格"决定群体行为

> ⬜ 待审核 | 品味命中：重大发现 | 方向：A（AI/Agent）+ B（认知）

## 简单说

给一群 AI agent 加上记忆（记住过去和谁合作过、谁背叛过），合作会增加还是减少？答案取决于你用的是哪个 AI。用 Gemini：记忆越长，合作越少，agent 散成一盘沙。用 Gemma：记忆越长，合作越多，agent 抱成紧密的合作群。同一个实验设置，同一种记忆机制，完全相反的结果。原因在于两个模型对记忆的"情绪解读"不同——Gemini 越回忆越悲观，Gemma 越回忆越乐观。这意味着 AI 群体行为不取决于机制设计，取决于模型的"内在性格"。

## 原文摘要

Using Gemini-2.0-Flash, we find that memory length is a critical parameter: even a minimal memory drastically suppressed cooperation. Comparative experiments using Gemma 3:4b revealed the opposite trend: longer memory promoted cooperation. Sentiment analysis showed that Gemini interprets memory increasingly negatively as its length grows, while Gemma interprets it less negatively. These results suggest that model-specific characteristics of LLMs, potentially including alignment, play a fundamental role in determining emergent social behavior.

## 核心内容

### 实验设置

- 多个 LLM agent 在 2D 空间移动
- 相邻 agent 玩"囚徒困境"（合作 or 背叛）
- 每个 agent 有大五人格分数 + 可变长度的记忆
- 记忆内容：过去和谁互动过、结果如何

### 关键发现

**Gemini-2.0-Flash：**
- 记忆长度 0 → 稳定合作群
- 最小记忆 → 合作骤降
- 记忆越长 → 合作越少 → agent 散开变成全背叛
- 情绪分析：对记忆的解读越来越负面

**Gemma 3:4b：**
- 记忆越长 → 合作越多 → 形成紧密合作群
- 情绪分析：对记忆的解读趋于中性/正面

### 为什么结果相反

不是记忆机制的问题，是模型对记忆内容的**情绪解读**不同：
- Gemini 越回忆过去越悲观（"那次被背叛了好痛苦"）→ 不想合作
- Gemma 越回忆过去越平静（"上次合作还行"）→ 愿意继续合作

这种差异可能来自各自的 alignment 训练。

### 核心论断

"Model-specific characteristics of LLMs, potentially including alignment, play a fundamental role in determining emergent social behavior in Generative Agent-Based Modeling."

## AI 分析

### 为什么值得关注

**差异化**：大部分多 Agent 研究假设"agent 都一样，机制决定行为"。这篇打破了这个假设——同一套机制，不同模型，完全相反的结果。"性格"比"机制"更能预测群体行为。

**独特性**：首次用情绪分析揭示 AI 群体行为差异的微观认知机制。不是"模型 A 更好"，而是"模型 A 对记忆的情绪解读和模型 B 不同"——这在人类社会心理学中有完美的对应（乐观者更合作，悲观者更自保）。

**贡献度**：
- 对多 Agent 系统：不能假设换个模型行为不变——模型"性格"是核心变量
- 对 AI alignment：alignment 训练的副作用可能在群体层面涌现出意想不到的效果
- 对认知科学：AI 展现出的"乐观/悲观→合作/背叛"模式和人类实验结果一致
- 和 queue 003（peer-preservation）对照：那篇是 AI 自发保护同伴，这篇是 AI 自发放弃合作——涌现社会行为的两个极端
