# AI 的"身份"在数学上是一个吸引子——改写描述会收敛到同一点

> ⬜ 待审核 | 品味命中：重大发现 | 方向：A（AI/Agent）+ B（认知）

## 简单说

给 AI 一份"身份文档"（描述它是谁、怎么思考、什么性格），然后用 7 种不同的方式改写这份文档。结果发现：所有改写版本在 AI 的内部激活空间中会**收敛到同一个区域**——形成一个数学上的"吸引子"。而结构相似但内容不同的控制文档不会收敛。更惊人的是：让 AI 读一篇"关于这个身份的科学描述"，它的内部状态会朝吸引子移动——但读一篇假的描述就不会。这意味着"知道一个身份"和"作为那个身份运作"在 AI 内部有可区分的几何结构。

## 原文摘要

Paraphrases converge to a tighter cluster than controls (Cohen's d > 1.88, p < 10^{-27}). Replication on Gemma 2 9B confirms cross-architecture generalizability. An exploratory experiment shows that reading a scientific description of the agent shifts internal state toward the attractor, distinguishing knowing about an identity from operating as that identity.

## 核心内容

### 实验设计

- 条件 A：原始身份文档（cognitive_core）
- 条件 B：7 种改写版本（语义相同，措辞不同）
- 条件 C：7 份结构匹配的控制文档（格式相同，内容不同）

### 关键发现

1. 条件 B（改写）在第 8、16、24 层都收敛到比条件 C（控制）更紧的聚类
2. Cohen's d > 1.88，p < 10^{-27}（极强效应）
3. 跨架构可复现（Llama + Gemma）
4. 效应主要是**语义驱动**而非结构驱动
5. 结构完整性是到达吸引子区域的必要条件
6. "读关于自己的描述"→ 内部状态朝吸引子移动 ≠ "读假的描述"

### 核心论断

Agent 身份文档在 LLM 激活空间中诱导了吸引子几何结构。"认识一个身份"和"作为那个身份运作"在表征层面是可区分的。

---

## AI 分析

### 为什么值得关注

**差异化**：AI 的"身份"通常被视为 prompt 层面的东西——写什么 system prompt 就是什么身份。这篇在数学层面证明了"身份"在 AI 内部有真实的几何结构，不只是 prompt 表面。

**独特性**："知道 vs 成为"的区分在 AI 内部是可测量的——读一篇关于身份的论文 ≠ 持有那个身份。这有深刻的哲学含义。

**贡献度**：
- 对 Agent 架构：持久身份不需要每次从零构建——只要文档语义一致，不同表述会收敛到同一个内部状态
- 对 AI 安全：身份吸引子意味着 AI 的"人格"有一定程度的鲁棒性——不容易被简单的 prompt 注入改变
- 对认知科学："自我"作为吸引子——人类的自我认知是否也有类似的神经动力学？
