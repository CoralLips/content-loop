# 博弈论信息论：用一个框架统一了概率和对抗两大分支

> ⬜ 待审核 | 品味命中：重大发现 | 方向：B（信息论）| ★★

## 简单说

信息论有两大分支，一直被认为不可统一：一个处理"随机噪声"（Shannon 的概率信道编码），一个处理"敌人故意捣乱"（对抗信道、零错误编码）。这篇论文用博弈论把它们统一了：编码 = 编码器和对手之间的确定性博弈。编码器可以"买保险"——根据信道输出获得赔付。通过把概率定价锥放宽为非凸向下封闭锥（恰好是建模信息传输所需的放宽），Shannon 的经典定理和对抗场景的定理都变成了同一个框架的特例。

## 原文摘要

We propose a unifying non-probabilistic information theory based on game theory and dynamic hedging which subsumes the conventional probabilistic channel coding theorem and lossless source coding theorem, as well as adversarial settings. Coding is modelled as a deterministic game between an encoder and an adversary, where the encoder may purchase insurance with a payoff that depends on the channel outputs.

## 核心内容

### 统一了什么

| 之前 | 概率信道编码 | 对抗/零错误编码 |
|------|------------|---------------|
| 框架 | 概率论 | 组合数学 |
| 假设 | 噪声随机 | 噪声由对手选择 |
| 关系 | 互相不包含 | 互相不包含 |
| **现在** | **都是博弈论框架的特例** | |

### 核心数学工具

- Ville/Shafer/Vovk 的博弈论概率：把概率事件重新定义为"赌博策略的收益"
- 本文的扩展：把凸定价锥放宽为非凸向下封闭锥
- 这个放宽恰好是建模信息传输所需要的——概率信道、对抗信道、任意变化信道都统一了

### 核心论断

"Pricing downward closed cone is a versatile tool for non-probabilistic coding results that can subsume their probabilistic counterparts."

## AI 分析

### 为什么值得关注

**差异化**：Shannon 的信息论是概率性的——假设噪声是随机的。但现实中噪声可能是对抗性的（黑客、干扰器）。两种情况一直用不同理论处理。这篇说：不需要两套理论，一套博弈论就够了。

**独特性**：不是"扩展"Shannon，是"从上方包含"Shannon——Shannon 的定理成为一个特例。这和 queue 038（语义率失真包含 Shannon 率失真）在精神上一致：都是从更一般的框架回看经典理论。

**贡献度**：
- 对信息论：可能是继 Shannon 之后最根本的框架扩展之一（如果数学正确的话）
- 对 AI 安全：对抗场景下的信息传输有了和概率场景统一的理论基础
- 理论链：Shannon(概率) → Kolmogorov(算法) → G理论(语义) → 语义率失真(逻辑) → **这篇(博弈)** = 信息论的五个视角
