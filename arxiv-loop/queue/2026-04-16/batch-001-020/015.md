# 多 Agent 联合越狱 AI：靠积累经验把攻击成功率推到 90%

> ⬜ 待审核 | 品味命中：有趣思路 | 方向：A（AI/Agent）

## 简单说

一个 AI 骗不过另一个 AI 的安全防线？那就派一群 AI 合作来骗。MemJack 框架让多个 AI agent 合作越狱视觉语言模型：一个负责分析图片里什么元素能被利用，一个负责伪装恶意意图，一个负责绕过防御层。更厉害的是，它有"记忆"——每次成功的越狱策略会被存下来，下次攻击新图片时直接调用。结果：对 Qwen3-VL-Plus 的攻击成功率从初始就很高，扩展到足够多轮后达到 90%。研究者还放出了 11.3 万条攻击轨迹的数据集，帮助防御者研究怎么堵这些漏洞。

## 原文摘要

We introduce MemJack, a memory-augmented multi-agent jailbreak attack framework that explicitly leverages visual semantics to orchestrate automated jailbreak attacks. MemJack achieves a 71.48% ASR against Qwen3-VL-Plus, scaling to 90% under extended budgets. We will release MemJack-Bench, a comprehensive dataset comprising over 113,000 interactive multimodal jailbreak attack trajectories.

## 核心内容

### 三个 Agent 的分工

1. **语义映射 Agent**：分析图片中的视觉实体，找到能和恶意意图关联的元素
2. **伪装 Agent**：通过多角度视觉-语义伪装生成对抗 prompt
3. **几何过滤 Agent**：用迭代零空间投影（INLP）绕过模型在潜在空间中的提前拒绝

### 记忆增强

- 成功的策略存入"多模态经验记忆"
- 新图片攻击时先查记忆，调用历史成功模式
- 多轮攻击中策略不断积累和优化

### 关键数据

- 对 Qwen3-VL-Plus：71.48% ASR（初始），90%（扩展预算）
- 攻击用的是完整的、未修改的 COCO val2017 真实图片（不是人造对抗样本）
- 释出 113,000+ 条攻击轨迹供防御研究

## AI 分析

### 为什么值得关注

**差异化**：之前的越狱方法是"改像素"（对抗样本）或"改文字"（prompt 注入）。MemJack 是"理解图片的语义，利用正常图片的语义关联来越狱"——不改一个像素，用真实图片攻击。

**独特性**：多 Agent 合作 + 记忆积累 = 攻击能力随时间增长。这和 queue 003（peer-preservation）是同一条线——AI 合作带来的不只是效率，还有不可预见的涌现风险。

**贡献度**：
- 对 AI 安全：视觉语义层的攻击面几乎完全未被研究过
- 对多 Agent 系统：Agent 协作 + 记忆 = 持续增强的能力，不管是好的还是坏的
- 113K 攻击轨迹数据集对防御研究极有价值
