# 越会推理的 AI 越不合作——想让它们合作，别劝，上合约

让两个 LLM 玩一局囚徒困境。直觉上你会想：推理能力越强的模型，越应该看清"合作更优"的大局，对吧？

实验结果完全相反。**推理能力越强的 LLM，越倾向于叛变**。Claude、GPT-5.2、Gemini-R、Qwen-30B——single-shot 社会困境下，几乎所有现代模型都选叛变。无论开不开推理、无论大小。

这不是"AI 不懂合作的好处"。牛津-剑桥-ETH Zurich 的一项新工作发现了一个更麻烦的事实：**它们懂，太懂了**。它们之所以叛变，是因为**博弈论教过它们"一次性博弈的纳什均衡就是叛变"**。模型在"按博弈论做理性选择"这件事上做得非常好——好到所有经典的"劝合作"手段都不起作用。

那么，能让它们合作吗？答案让人挺意外。

## 先说清什么叫"社会困境"

四个经典游戏：囚徒困境、旅行者困境、信任游戏、公共物品游戏。它们有一个共同结构：**对每个人来说，"叛变"永远比"合作"多拿一点；但如果大家都叛变，总分比大家都合作低**。

囚徒困境最熟悉：两人同时合作每人得 3 分，都叛变每人得 1 分，但如果一个合作一个叛变，叛变的拿 5 分、合作的拿 0 分。理性个体在"对方选啥我都该叛变"的逻辑下，会选叛变——但两人都这么想，就都只拿 1 分，比都合作的 3 分差。

这就是"集体理性与个体理性的冲突"——人类社会花了几千年的时间，发明法律、契约、声誉系统、调解员，本质上都是在解决这个问题。

这篇论文做的事：**把人类文明里这些合作机制搬到 LLM 群体里，看看哪个有效**。

## 基线：LLM 一开局就叛变

没有任何机制约束时，测试的六个模型（Claude、GPT-5.2、GPT-4o、Gemini-R、Gemini-B、Qwen-30B）在四个游戏里的合作频率大概在 **0.26 到 0.40** 之间——也就是说大多数时候都选叛变。

更关键的是一个分析：作者让 LLM 把推理过程吐出来，用另一个 LLM 当裁判去分类。**绝大多数叛变决策都是理由充分的**——"我已经评估了对方可能的策略"、"叛变是占优策略"、"这是纳什均衡"。

换句话说，**LLM 不是不会合作，是"想明白了之后选择不合作"**。推理模型比非推理模型更理性地叛变——因为它们对博弈结构想得更清楚。

这对 AI 安全来说是个坏消息：你让 AI 变得更聪明、更擅长推理，它在社会困境里会变得**更自私**，不是更合作。

## 四种合作机制，两种有效两种拉胯

作者测试了四种博弈论上成立的合作机制：

**重复博弈**：把一次性博弈变成"还会再见"。理论上"无限重复能让合作成为均衡"（这是 folk theorem）。

**声誉系统**：玩家之间可以看到对方的历史行为——叛变过的人下次会被避开。

**第三方调解**：双方把决策权委托给一个中立的 LLM，由它给出建议并代为执行。

**合约**：双方签订"按结果付款"的合约——比如"如果你合作我就给你 1 单位转账"，签订后由系统自动执行。

结果让人意外：

| 机制 | LLM 合作率（典型值） |
|------|------|
| 无机制基线 | 0.3 左右 |
| 重复博弈 | 0.3-0.4 |
| 声誉系统 | 0.25-0.32 |
| 第三方调解 | **0.76-0.87** |
| 合约 | **0.85-0.88** |

**重复博弈和声誉系统几乎无效**——虽然博弈论证明它们应该有效。合约和调解把合作率拉到 80% 以上。

为什么会这样？

## 为什么"讲道理"不管用，"签字"管用

重复博弈的效果来自"下次还会见面，你最好对我好点"——它依赖**记忆**和**对未来的预期**。问题是：实验发现，当**对手不断变化**时（真实世界里的 Agent 生态就是这样），LLM 无法从"上轮对方怎么对我"稳定推出"这轮我该怎么做"。更糟的是，哪怕对手一样，**几轮之后 LLM 就不"记仇"了**——它默认这局和上局是独立博弈。

声誉系统更惨。看到对方"上一轮叛变过"并没有让 LLM 更谨慎——它们倾向于认为"过去不代表现在"，依然按本局博弈结构做理性选择。

合约和调解为什么有效？因为它们**改变了博弈本身的 payoff 结构**——不是在心理上劝说，而是在规则上重写。

合约把"如果我合作他叛变我就吃亏"这个最大的担心直接消除了：合约条款规定"如果一方叛变，合约自动扣钱转给另一方"。这时"叛变"不再占优了——叛变的代价被合约本身重新定义。LLM 算得很清楚：**新的规则下，合作才是占优策略**。

调解的机制不同但思路类似——把决策权委托给一个中立第三方后，"我要不要信任对方"这个问题被替换成了"调解员会给双方开什么建议"。一个设计得好的调解员会在博弈论意义上建议双方合作，而双方都知道这一点，所以接受建议。

**这两个机制的共同点**：**它们不是在说服 LLM 做反理性的选择，而是在理性的基础上重写游戏**。LLM 在新游戏里依然按纳什均衡推理，但新游戏的均衡变成了合作。

## 最反直觉的发现：演化压力让合作更强

最后一个实验让人真正感到意外。

作者设置了一个进化环境：不断让收益低的 LLM 被淘汰、收益高的 LLM 繁衍。直觉上这应该让"自利"成为主流——毕竟自私的个体在单局中拿的多。

但实际结果相反：**在有合作机制的环境下，演化压力反而把合作率推到接近 100%**（合约下合作率从 0.85 左右升到 0.93-1.00）。

为什么？因为有合约的环境下，叛变的人在合约条款下反而会**被扣走收益**——叛变才是低效策略。演化就淘汰了那些"不愿意签合约"或"签了合约又违约"的个体，留下理解合约价值的个体。

换句话说，合作机制不仅立刻有效，还**经得起长期演化筛选**。这对多 Agent 系统的工程意义是：**我们不需要担心"以后 Agent 变得更聪明就不受约束了"——只要规则本身是理性站得住脚的，越聪明的 Agent 会越遵守它**。

## 这对 AI Agent 的启示

未来会有越来越多 LLM Agent 在共同环境里互动——代理我们谈判、代理我们交易、代理我们写代码。如果按"让模型更聪明，它自然会合作"的路径走，这篇论文给了一个明确的否定答案。

真正的启示是：**Agent 生态需要合约执行基础设施，不是靠 prompt 说"请合作"**。

这听起来很像人类文明的建立过程——我们不是靠教育和道德让陌生人合作的，我们是靠**法律、合同、保险、仲裁**这些可执行的结构让合作成为理性选择。现在，我们需要为 AI Agent 搭建同一套基础设施。

推理能力本身不会带来合作。**能被执行的规则**才会。
