# 怎么区分"有意义"和"纯噪声"？一个 60 年前的数学家给出了答案

一串随机数字和一首诗，哪个信息量更大？

Shannon 的信息论会说：**随机数字**。因为它最不可预测，每个字符都是"惊喜"。

但这显然违背直觉——**随机噪声有什么"信息"可言？**

1965 年，苏联数学家 Andrey Kolmogorov 从完全不同的角度给出了另一个答案。他的定义看起来和 Shannon 毫不相关，但最终两者并肩成了信息论的**两根支柱**，各管一件不同的事。

更早一点——**1960 年美国人 Ray Solomonoff 独立做出了同样的定义**，但发表在一个不知名的期刊上，几乎没人注意。Kolmogorov 的名字留下来了，Solomonoff 的没有。这种独立发现在科学史上不罕见，但这次格外可惜——因为这个定义是 20 世纪下半叶信息理论最深刻的一个。

---

## Kolmogorov 的核心想法

**一个东西的信息量 = 描述它所需要的最短程序的长度。**

来看三个例子：

**"010101010101010101010101"**  
看起来很长。但你只需要说"**重复 01 十二次**"。最短描述很短 → 信息量低。

**"110100110010110100010010"**  
看不出任何规律。你只能**原样写出来**。最短描述 = 它本身 → 信息量高。

**π 的前 100 位**  
看起来很随机。但你可以说"**算 π 到 100 位**"。最短描述是一个计算程序 → 信息量中等。

这就是 Kolmogorov 的核心定义——**K(x) = 能输出 x 的最短程序的长度**。

## 和 Shannon 的本质区别

Shannon 和 Kolmogorov 表面上对"随机" vs "有规律"的判断是一致的——都说随机高、规律低。但**他们衡量的对象不一样**：

| | Shannon | Kolmogorov |
|--|---------|-----------|
| 衡量什么 | **一个随机源**的平均信息量 | **一个具体对象**的复杂度 |
| 问的问题 | 从这个源平均能得多少信息 | 这个具体东西多难描述 |
| 角度 | 概率 / 统计 | 算法 / 个体 |

Shannon 看的是"类"——我知道这是一枚公平硬币，所以每次抛掷**平均**给我 1 bit 信息。

Kolmogorov 看的是"个体"——我手上这一串 "HTHTHTHT"，**具体**需要多长的程序描述它？答案是很短（"重复 HT"），不管它来自什么源。

**两个框架互补，不互斥**。Shannon 管"信息源"，Kolmogorov 管"信息物"。

## 最精彩的部分：区分"意义"和"噪声"

两个理论对随机噪声的"信息量"判断都高。区别在哪？

**Kolmogorov 能进一步拆开"有规律"的部分和"随机"的部分。Shannon 做不到这件事**。

后续研究者在 Kolmogorov 的基础上发展出了 **Kolmogorov 结构函数**——它能把任何一个对象的信息拆成两部分：

**有规律的部分**：能被一个简短模型解释的 → 这是"**有意义的信息**"  
**随机的部分**：模型解释不了的余量 → 这是"**噪声**"

比如你拿到一组实验数据：

```
数据 = 规律（y = 2x + 1）+ 噪声（测量误差）
```

Kolmogorov 框架能告诉你：这组数据中，"y = 2x + 1"这个规律是有意义的信息（因为它极大压缩了数据），剩下的波动是噪声。

**这在数学上形式化了奥卡姆剃刀：最好的解释是最短的那个。**

这不是一个直觉表述——是一个严格的数学定理。一个模型如果能让数据"描述更短"（总描述长度 = 模型长度 + 残差长度），它就是更好的解释。

## 一个优美的不可能

但这里有个转折：

**Kolmogorov 复杂度是不可计算的。**

你没法写一个程序来精确计算任何对象的 Kolmogorov 复杂度。这已经被数学严格证明了——证明来自**图灵停机问题**的不可判定性。

简单说：要算 K(x)，你要遍历所有可能的程序，找出最短那个能输出 x 的。但你没法知道一个程序会不会永远跑下去（停机问题）——所以你永远无法排除"可能还有更短的程序你没发现"。

这看起来很致命——**一个算不出来的理论有什么用？**

但数学家并不这么看。Kolmogorov 复杂度就像圆周率——**你永远算不出精确值，但可以无限逼近**。

## 能用：最小描述长度原理

在实践中，我们用**最小描述长度**（Minimum Description Length, MDL）等方法来近似 Kolmogorov 复杂度，效果非常好。

MDL 原理一句话：**在拟合一组数据时，选使得"模型描述 + 模型未解释的残差"总长度最短的那个模型**。

这在机器学习里是一个核心原则——**模型太简单会欠拟合（残差大），模型太复杂会过拟合（模型描述长）**。最优模型是让两者之和最小的那个。

现代深度学习的泛化行为、模型选择、数据压缩，底层都有 Kolmogorov 复杂度 / MDL 的影子——虽然不能精确计算，但作为指导原则处处在用。

## 不可计算揭示了一个更深的事实

Kolmogorov 复杂度的不可计算性，不是个 bug，是个 feature——**它揭示了"意义"的判断本质上是困难的**。

**没有一个万能算法能自动判断"这个东西有没有意义"。** 人工智能、科学研究、艺术鉴赏里那种"这看起来有深意" / "这就是乱涂"的判断，不是因为人类太主观——**是因为从数学上就没有一个客观自动的判断方法存在**。

Kolmogorov 用一个不可计算的量定义了"意义"，这件事本身就在说：**意义不是一个可以机械提取的属性，是需要"解释"的属性**。

## 和 AI 的关系

回到开头的问题：一串随机数字和一首诗，哪个信息量更大？

- **Kolmogorov 复杂度 K**：随机数字更高（因为不可压缩），诗较低（因为有押韵、结构、语言规律）
- **"有意义信息"**：诗更多（因为它的 K 里绝大部分是"规律"——模型部分），随机数字几乎全是"随机"（残差部分）

两者不一样。**K 高 ≠ 有意义。有意义 = K 里模型部分占比大**。

这给 AI 研究提供了一个重要视角：

**AI "理解"了什么 = AI 的内部模型从数据中压缩出了多少规律。**

一个好的 AI 模型，本质上就是一个好的"压缩器"——它用尽可能短的描述捕捉了数据中尽可能多的规律。**剩下压缩不了的，就是噪声**。

这个视角在近年越来越被重视——从压缩的角度评估 AI，和从"预测下一个 token"的角度评估，其实在数学上是等价的（都在最小化描述长度）。

## 三根支柱的信息论

Shannon（1948，概率 / 统计视角） + Kolmogorov（1965，算法 / 个体视角） + G 理论（2025，语义 / 真值视角）= **信息论的三个互补维度**。

三者各自回答不同的问题：

- Shannon：**这个消息源每秒给我多少 bit 信息？**
- Kolmogorov：**这个具体东西有多复杂？有多少是规律，有多少是噪声？**
- G 理论：**这条消息说的有多大程度是对的？接收者能从中学到多少？**

每一个视角都不能被另外两个代替。三者合起来，才构成"信息"这个概念的完整边界。

---

一个 60 年前的苏联数学家，给"信息量"下了一个**永远算不出来但处处在用**的定义。

这不是缺陷。这是因为：**"意义"本来就不是一个可以被完全算出来的东西**。
