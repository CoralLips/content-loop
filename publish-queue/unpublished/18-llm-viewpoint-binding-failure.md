# LLM 脑子里有"指南针"，却读不懂自己——被 ACL 2026 抓到的一个精确失败点

闭上眼睛，你在自己的房间里转半圈。

你大概还是能"看"到——知道身后是门、左边是窗、面前是柜子。你的大脑里有一张空间地图，哪怕没有视觉输入，它也在运转。这叫 **spatial imagery**，是人类认知的基本能力。

那 LLM 呢？只给它纯文字："你初始面朝北，左边是桌子、右边是椅子、前面是书柜。现在向右转 90 度，再向左转 45 度。问：你的左边现在是什么？"

人类做这个任务 **100% 正确**。LLM——Claude、GPT、Qwen、各种大小、各种架构——**全部做不到**。

这是一篇被 ACL 2026 主会接收的论文。更有意思的是，作者没停在"LLM 不行"，他们把模型剖开了看——发现了一个精确到层、精确到注意力头的失败点。

## 他们造了一个 2 万题的"纯文字旋转"测试

任务很单纯：模型被放在一个虚拟房间里，初始面朝某个方向，周围有一些物体（从 100 个常见室内物体里抽），执行 2-5 步的旋转，问它现在能看到什么。

数据集叫 VRUBench，共 19591 道题：2 步旋转 4614 道、3 步 4977 道、4 步 5000 道、5 步 5000 道。旋转角度限制在 90° 和 45° 的倍数——就是人类脑补时最顺手的那几种。

人类做这个 100%。LLM 即使是强推理模型（比如开 CoT、Gemini-R 这种），正确率也低到让人吃惊。有意思的点来了：**推理模型和非推理模型差距非常小**——CoT 并没有真的帮助 LLM 做好"脑子里的几何"。Scaling law 有效但收益很慢——更大的模型只是稍好一点，离 100% 还差一大截。

这说明：**"脑补空间"不是多训练几倍数据就能自动学会的能力**。它是一个结构性缺口。

## 剖开模型：视角信息藏在中间层，但传不到答案

作者用了 mechanistic interpretability 的两个标准武器。

**第一个武器叫 probing**。你在模型的每一层隐藏状态上训练一个很小的分类器，测试"这一层到底编码了什么信息"。探针读得出"当前视角"——说明这一层**已经知道**模型现在转向哪了。

结果让人意外：**模型的中间层真的编码了正确的视角方向**。探针能从这些层读出"我现在朝北"、"我现在朝南"——准确率很高。

也就是说，LLM **其实算对了视角**。问题出在后面。

**第二个武器叫 path patching（路径打补丁）**。这是因果干预：你把某一个注意力头的输出换掉，看最终答案有没有变化。如果这个头对任务关键，换掉它就会让准确率掉下来。通过这种穷举，作者定位出了**一小组关键注意力头**——它们承担了视角推理。

然后作者看这些关键头"在看什么"。发现它们正确地注意到了旋转步骤和当前方向的 token——**说明它们知道自己在算什么**。

但最终答案还是错的。

## "绑定失败"：知道北在哪，但对不上"北面有什么"

作者的诊断很精确：

**模型知道自己朝北。模型也知道"北面应该是书柜"。但它没把这两件事绑起来——最终输出时，它可能报告"北面是椅子"**。

这在认知科学里有个经典名字叫 **binding problem**（绑定问题）——大脑如何把"颜色是红"和"形状是圆"绑定到"同一个物体"上。1980 年代 Anne Treisman 就提出了这个问题，它一直是感知和注意力研究里的硬骨头。

现在同一个问题出现在 LLM 里：**特征都被提取了，但绑不起来**。

论文里的原话是："虽然模型在隐藏状态里编码了视角信息，但它似乎难以把视角位置和对应观察绑定起来，导致最终层出现幻觉。"

这跟我们日常说的"AI 幻觉"不是一个意思。日常幻觉是模型编了一个听起来合理的事实。这里的幻觉更精确——**每一块拼图都算对了，但拼回去的时候错位**。

## 只修 10 个头，效果接近全量微调

这篇论文最实用的发现在这里：既然失败定位到了一小组注意力头，**那修这些头就够了**。

作者做了"选择性微调"：只更新通过因果干预识别出的关键头，其他所有参数都冻住。结果——

**用 50% 的 GPU 时间，达到了和全量微调接近的效果**。并且，因为 99% 以上的参数没动，模型的通用能力没有被破坏——没有"为了学会空间推理，把别的能力掉了"的副作用。

这对训练圈是个实质提示：**很多"LLM 做不到"的任务，可能不是"整个模型没这能力"，而是"几个头没对齐"**。用 interpretability 工具定位失败点，然后做外科手术式的微调，比无脑 SFT 更精准、更省钱、副作用更小。

## 一个更大的问题

这项研究最让人回味的地方不是"VRU 这个具体任务做不好"。

而是：**LLM 的内部语义表征，远比它表面的输出丰富**。中间层掌握了很多信息，但这些信息没能正确地传到最终层、变成答案。

这意味着当我们测试"AI 会不会做 X"的时候，我们其实在测两件事：
1. **AI 的内部模型有没有算出 X**
2. **这个算出来的 X 有没有被正确读取和输出**

这两件事可以分开失败。一个 LLM 可能内部明明算对了，但在最后一步把答案搞丢。反过来，一个 LLM 也可能内部根本没算，只是从训练数据里记住了一个相近答案。

过去我们只能看第二件事——它最终说对了没有。现在 interpretability 工具让我们能分别看第一件事了。**很多"AI 不行"的结论可能要被重新审视**——可能它行，只是输出链条在某个环节掉了。

在 Agent 和具身智能越来越重要的今天，"空间推理"这个基础能力会变得关键。这篇论文给出的思路是：**不是从头造一个会空间推理的模型，而是找到现有模型里的断点，把它焊上**。
