# AI 的 MoE "专家分工"是个集体幻觉

大模型圈子里有一个广为流传的故事：**MoE（Mixture of Experts）架构**里有很多"专家"，每次只激活一部分——"数学专家"管数学，"语言专家"管语言，"代码专家"管代码。效率高、分工细，让模型既大又快。

**这个月一篇论文证明：专家分工是我们脑补的。**

所谓的"专家特化"不是在按领域分工，是路由器按几何结构分的——**不同的专家激活，主要反映的是 token 隐藏状态在高维空间里的方向，不是语义领域。** MoE 的效率是真的，它的"可解释性"是假的。

---

## 最关键的实验：60% 对 60%

论文做了一个设计简单但结论炸裂的对比实验。

他们用 30 道 HMMT 数学竞赛题，让 60 个不同的 MoE 推理模型解题，对比激活的专家集合。然后算了两种重叠：

1. **同一道题，不同模型**——模型 A 和模型 B 在解同一道数学题时，激活的专家有多少重合？
2. **不同题，同一模型**——模型 A 在解数学题和解完全无关的题时，激活的专家有多少重合？

结果：**两种条件下的重叠率，都是大约 60%。**

这一组数字把"专家特化"叙事干净利落地砸了。

按"专家分工"的故事，答案本该是——模型 A 和 B 解同一道数学题时应该都调"数学专家"，重叠率应该很高；模型 A 解数学题和解无关题时应该调不同专家，重叠率应该很低。

**实际数据：两者没差别。** 解同一题和解不同题，专家重叠率一样。这意味着激活模式和题目语义之间几乎没关系。

## 一个更夸张的例子：温网维基 vs HLE 考题

论文在深层还发现了一个更反直觉的现象。

他们把一段**人类最难考试（HLE）**的题目（411 个 token）和一段**温布尔登网球锦标赛的维基百科**（2500 个 token）分别输入同一个模型，看深层的专家激活。

**深层的专家集合几乎完全一样。**

两段文字在语义上没有任何交集，一个是高难度推理题，一个是体育比赛介绍。但在 MoE 的深层，它们都触发了同一批"专家"。

这和"数学专家 vs 语言专家"的分工叙事，差的不是一点半点，是整个故事垮了。

## 为什么会这样：路由器是线性的

论文给了一个清晰的机制解释。

MoE 的路由器本质上是一个**线性映射**——把 token 的高维隐藏状态投影到几个数字，按这些数字决定激活哪些专家。

线性映射有一个基本性质：**输入在几何上接近的 token，输出也接近。** 如果 token A 和 token B 的隐藏状态向量指向差不多的方向，它们就必然激活差不多的专家——跟这两个 token 的语义内容没关系。

更深一层：**大模型的隐藏状态在深层会发生"秩崩溃"——所有 token 的向量越来越趋同**（这是 Transformer 的一个已知现象）。在深层，温网维基的 token 和 HLE 考题的 token，向量方向已经接近。所以深层专家激活一样。

路由器看到的不是"这是数学还是语言"，是"这个向量朝哪个方向"。**方向决定路由，语义只是顺便相关。**

## 浅层还能工作，深层就塌了

论文也注意到一个有趣的层级差异。

**浅层的专家**：还能看到"按 token 身份分"——"apple"、"数学符号"、"中文字符"这类表面特征会影响路由。这层有一点"分工"的味道。

**深层的专家**：完全是几何的事。所有 token 在深层经过秩崩溃，隐藏状态趋同，路由器分不清"这个 token 出自什么话题"。

深层还有一个更荒唐的现象：**负载平衡损失让路由器主动抑制"共享方向"**——强行给不同 token 分不同专家，维持使用率均衡。但这种"被迫分化"不是按语义的，是按随机的副产品。

结果就是：你看到的那个"某某专家特化于法律"的现象，要么是浅层的 token 表面特征，要么是深层的几何巧合——**都不是"它懂法律"**。

## "专家分工"的叙事是人投射的

为什么这么多人相信专家分工？论文的洞察是：**人类倾向于把任何结构化的东西解读成"有意义的分工"，哪怕实际上只是几何。**

你看到有"专家"这个名字，每个专家有权重、有激活模式，就自然脑补出"数学专家、代码专家"的画面。但这些"专家"的真实身份，是线性代数里的几个投影方向，不是领域专家。

这个认知偏差本身在 AI 可解释性研究里有名字——叫"**解释性投射**"：有意义的可视化 ≠ 系统内部真的有意义地分工。

## 这对 MoE 可解释性意味着什么

论文的结论尖锐：**要理解 MoE 的专家特化，至少和理解 LLM 的隐藏状态几何一样难。**

而隐藏状态几何，**本身就是 LLM 可解释性里最难的开放问题**——几乎没有人真的搞明白。

这等于说：**我们以为"专家分工"给了 MoE 一层额外的可解释性，但这层可解释性是假的。** 它把问题转化成了一个更难的问题。

对 MoE 的工程应用这不是坏消息——效率优势依然真实存在，路由本身能工作。但对"我们真的懂这些模型在做什么"的期待，这篇论文把那个期待的上限拉低了一格。

## 三个独立的崩溃

- **跨模型重叠 = 噪声水平**：不同模型的专家激活对比不上"信号"，只是随机重叠
- **预填充 ≠ 生成**：模型读输入时的专家激活，预测不了它写输出时的专家激活
- **解释性抗推广**：基于一个模型、一种输入的专家激活做的解释，不一定推得到其他情境

每一条都是一个独立的失败——合起来是"MoE 可解释性要从头来"。

---

**所谓的"专家"，只是隐藏状态几何在高维空间的影子。**

我们在影子上看到的分工，是自己投射上去的。真正的机制，藏在那个还没被任何人真正理解的几何里。
