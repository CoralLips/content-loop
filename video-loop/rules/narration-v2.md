# 口稿规范 · v2 谜题切片（3-4 min 实验 pipeline）

**适用**：`script/{ep}-v2-narration.md`（每期 v2 极简版，手动触发）
**定位**：单谜题深潜。不做全景，只做一个"常识错在哪、新工具怎么解"的锐利切片。
**目标时长**：3-4 分钟（≈ 800-1100 字，Fish Audio speed=0.9）

---

## 风格约束

| 维度 | 约束 |
| --- | --- |
| 语感 | 冷峻句感 + 保留叙事连接词。不念论文，也不抒情 |
| 结构 | 5 Act：**谜面 → 常识错在哪 → 新工具 → 谜底 → 余韵** |
| 句子长度 | **≤ 25 字/句**，均长 ≤ 20 字。单句超 30 字拆开 |
| 连接词密度 | **≥ 1 个 / 3 句**（为什么/但是/所以/这意味着/问题是）。冷峻 ≠ 断裂 |
| 术语 | **白名单外术语必须有白话铺垫** 或 **注解标记**（Annotation 组件会在画面底部显示）。不铺垫又不标注 = 退回 |
| 画面双声部 | 旁白抽象，画面给具象（三段论示例 / 数字 / 对比）。旁白不要复述画面在做什么 |

## 硬性红线

- ❌ 视觉符号进旁白：`——` / `／` / `→` / `=` / `「」` / `《》`
- ❌ 单句超 30 字（v2 不允许长句挤压听感）
- ❌ 连续 4 句无连接词（听感断裂，单次入耳不成句）
- ❌ 金句堆砌（punchline 密度每 150 字不超过 1 个，否则稀释）
- ❌ 重复 v1 的"论文导览"路径（如果和 v1 是同一谜题，v2 必须换视角）
- ❌ 幕头语法不统一：**必须** 用 `## Act N · XXX`（H2 + `·` 分隔符）。`# Act N XXX`（H1 无分隔符）禁用。原因：H1 会让渲染层（TSX）误以为"每幕是独立章节 → 该有章节横幅"，破坏冷峻书面体美学。见 14-v2 章节横幅事故。

## v1 vs v2 差异化矩阵

| 维度 | v1 导览式 | v2 谜题切片 |
| --- | --- | --- |
| 视角 | 论文章节顺序 | 单一"常识错在哪"驱动 |
| 入口 | "这篇论文做了..." | "这不可能 → 这居然可以 → 凭什么" |
| 覆盖 | 全景 + 所有主要结论 | 1 个核心定理 + 1 个 punchline |
| 语感 | 口语主持 | 冷峻书面 + 叙事连接 |
| 画面 | scene 对应论文章节 | Act 对应谜题节拍，注解化解术语 |

**判定规则**：如果 v2 删掉后 v1 没损失任何信息，v2 没必要存在。v2 必须提供 v1 给不了的"紧张感"。

## 正例（02a Act3 新工具段）

> 本月这篇论文给了新判据。叫推理闭包一致。意思是：能推出来的结论对齐，就算传到了。

三句全部 ≤ 18 字。连接词 2 个（意思是 / 就算）。术语"推理闭包"有白话铺垫（能推出来的结论对齐）+ Annotation 组件在画面底部弹出"所有能从已知推出来的结论"。

## 反例（v2 第一版被退回）

> 用推理闭包保真度替代字符对齐，零失真最小码率只需传不可约核，冗余高达 80%+。

单句 36 字，3 个白名单外术语连堆，零铺垫零连接，语言层听不懂。违反单句长度 + 术语密度 + 连接词密度。

## 验证

```bash
node bin/verify-narration.mjs script/{ep}-v2-narration.md --preset v2
```

v2 preset 会加严：单句 ≤ 25 字、连接词密度 ≥ 1/3 句。不通过就改稿。

## 注解（Annotation）机制

v2 允许一部分术语不在旁白铺垫，代价是**必须在画面上用 Annotation 组件补课**：

```tsx
<Annotation enter={320} exit={500} term="推理闭包" gloss="所有能从已知推出来的结论" />
```

- `term`：术语本身
- `gloss`：≤ 16 字白话（画面底部淡显）
- 入场 = 术语第一次出现的帧 - 20，出场 = 该 Act 结束或下一术语入场

每期 v2 注解数量 3-5 个，超过 5 个说明术语过载，回头改口稿。
