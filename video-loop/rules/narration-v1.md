# 口稿规范 · v1 导览式（7 min 主 pipeline）

**适用**：`script/{ep}-narration.md`（每期主口稿）
**定位**：论文全景导览。逐段讲，把读者从"没听过"带到"能复述主干"。
**目标时长**：6-8 分钟（≈ 2000-2800 字，Fish Audio speed=0.9）

---

## 风格约束

| 维度 | 约束 |
| --- | --- |
| 语感 | 口语，不书面。主持人在对面说话，不是学者在念书 |
| 每段结构 | **铺垫 → 具象 → 结论** 三拍，缺一个就过抽象 |
| 段落长度 | 80-120 字/段，最长 150 字。超过拆开 |
| 句子长度 | 平均 ≤ 40 字，单句 ≤ 80 字 |
| 连接词 | 至少每 2 句 1 个（所以/但是/也就是说/换句话说/问题是） |
| 具象例子 | 每个抽象概念必须配一个数字 / 类比 / 画面 |
| 术语 | 白名单外术语（见 config.verification.narration.unwhitelisted_terms）必须有定义标记（"叫做"/"就是"/"翻译过来"/"它说的是"）在 ±50 字内 |

## 硬性红线（踩一条就退回重写）

- ❌ 视觉符号进旁白：`——` / `／` / `→` / `=` / `「」` / `《》`。TTS 读不出来
- ❌ 数学公式、LaTeX 片段、代码块。画面上放
- ❌ 连续 3 段都是抽象论述（用 `max_consecutive_abstract_chars: 150` 拦）
- ❌ 一段里出现 ≥ 3 个白名单外术语且没铺垫
- ❌ Markdown 粗体 / 斜体作为"语气标记"（TTS 忽略，等于白打）

## 正例（02a Scene2 Shannon 段）

> 要理解这件事为什么反常，得回到 1948 年。香农那年发表了《通信的数学理论》，给信息量算出了一个硬下限——**熵**。**从那以后的七十多年里，大家默认这就是极限了**。传得比熵还少？不可能。

三拍齐：铺垫（回到 1948）→ 具象（香农 + 熵 + 七十年）→ 结论（传得比熵还少不可能）。连接词 3 个（要理解 / 从那以后 / 比熵还少？）。

## 反例（早期版本被退回）

> 率失真理论给出了失真约束下的最小码率，这是信道容量概念的延伸。

单句 37 字但堆了 3 个术语（率失真 / 失真约束 / 信道容量 / 码率），零铺垫零具象零连接。违反术语密度 + 缺具象 + 硬红线（数学化书面）。

## 验证

```bash
node bin/verify-narration.mjs script/{ep}-narration.md --preset v1
```

v1 preset 会加严：连接词密度检查、三拍结构抽查。不通过就改稿，不要改 verify 规则。
