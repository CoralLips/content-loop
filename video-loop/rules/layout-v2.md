# Layout v2 规则 · 冷峻书面体画面编排

**适用**：v2 谜题切片每集 `script/{ep}-v2-layout.md` + v2 Act TSX 实现
**定位**：给画面一个"口稿"。和 narration 对照过审后再做 TSX。

---

## 哲学（3 条硬规则）

1. **静镜优先**。每页一次整体淡入，定镜停留，淡出切下一页。像翻书，不像幻灯片。**禁止**元素逐个累加（`useFadeIn`）。理由：累加看着像"花里胡哨"，破坏冷峻审美。14-v2 旧版累加被判为反面教材。

2. **画面不重复旁白**。旁白已说清楚的字，画面不重复呈现。画面只画**重点**：关键术语、核心对比、结论数字。装饰性小注、过渡符号、冗余标签全砍。

3. **少页 + 密信息**。每页信息密度可以高（≤ 3 元素静态上屏），但页数要少。**全集 ≤ 10 页**。宁可一页多看 2 秒，不要多切一次页。

---

## 硬性红线

| 规则 | 约束 | 理由 |
|---|---|---|
| **全集页数** | v2 Act Page 总数 ≤ 10 | 切换次数多 = 碎片感 |
| **单页元素** | ≤ 3 个视觉元素 | 超过就挤，看不过来 |
| **单页时长** | 6s ≤ t ≤ 20s | <6s 来不及读；>20s 走神 |
| **动画方式** | 只用 `usePage`（整体淡入淡出）| `useFadeIn` 累加禁用 |
| **幕头元信息** | 禁用 "Act N · XXX" 章节横幅 | 见 rules/episode-checklist.md Gate 3.5 |
| **画面 ≠ 旁白复读机** | 画面文字与旁白应互补，不复刻 | 观众听见 + 看见，不是听见两遍 |

---

## 推荐的页数分布（共 ≤ 10 页）

| Act | 建议页数 | 每页目标时长 | 备注 |
|---|---|---|---|
| Act 1 谜面 | 2 页 | 5-8s | hero 一页 + 钩子一页 |
| Act 2 常识错在哪 | 2 页 | 7-14s | 常识+Searle 合页、卡住独立页 |
| Act 3 新工具 | 2 页 | 7-14s | 三定义一页、反例一页 |
| Act 4 谜底 | 2-3 页 | 8-14s | 内容最密，最多 3 页 |
| Act 5 余韵 | 1-2 页 | 10-15s | hero + 表格 + 落点可同框 |
| **总计** | **≤ 10** | | |

---

## 三种 Page 元素分配模式

**模式 A · 单一 hero**（强调句 / 转折 / 钩子）：
- 1 元素：居中大字一句话
- 例：Act 1 Page 1 「什么是智能？」

**模式 B · 核心 + 辅证**（主句 + 支撑）：
- 2-3 元素：主标题 + 辅助描述 + 可选结论
- 例：Act 2 Page B 「中文房间 / 不懂中文的人照查询表答题 / 查表 ≠ 理解？」

**模式 C · 堆叠不累加**（同框多元素）：
- 3 元素**一次整体**出现在同一页（非累加）：hero + 主体 + 收束
- 例：Act 5 Page A 「把公式套回你自己 / 对比表 / 智能密度差 1000×」
- 关键：**一次呈现**，不做"hero 淡出让位主体"这种 PPT 切换动画

---

## 该砍什么（从 14-v2 累加版反例总结）

每页之外的装饰元素，能砍则砍：
- ❌ "1980 · Searle" 年代小标签 → 旁白说过就够
- ❌ "关键 · 独立" 引导小标题 → 直接上主句
- ❌ "查表 → 也能答题" 的 "→" 装饰箭头 → 用纯文字
- ❌ "物理装不下" 单行收尾 → 旁白已说
- ❌ 底部小字注脚（但 Annotation 术语释义组件保留）
- ❌ 章节横幅（Gate 3.5 硬禁）

## 正例（下一集参考）

**Act 1 · 2 页**

```
Page 1 (≤ 7s)  — 模式 A
  "什么是智能？" (hero 居中)
  "哲学家两千年 · AI 界七十年" (hero 下方小字，同屏同时出现)

Page 2 (≤ 4s)  — 模式 B
  "一个定义都立不住，整个学科就没有底" (主句)
  "直到这个月" (绿色副句)
```

**Act 5 · 1-2 页**

```
Page A (≤ 13s)  — 模式 C · 同框堆叠
  "把公式套回你自己" (顶部 hero)
  对比表: 笔记 10000/10000 · 原则 10/10000
  "智能密度差 1000×" (底部大字)
  （三者同时整体淡入，不做内部转场）

Page B (≤ 6s)  — 模式 B
  "差别不在感觉，在描述长度会不会随规模膨胀"
  "记住 / 懂了 · 那条线，现在可以算"
```

## 反例（14-v2 做过但不要学）

- Act 4 Page 3 累加 6 个元素（上下两层推理链）→ 像 PPT 爆炸动画
- Act 5 Page A 做 "hero 淡出再进表格" 的过渡 → 像 PPT 切换动画

**对照记忆**：冷峻美学 = 纸面感。翻一页、停一停、再翻一页。不是"字飞进飞出"。
